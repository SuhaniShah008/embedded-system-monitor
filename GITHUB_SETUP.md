# Quick GitHub Setup

From inside this project folder, run:

```bash
git init
git add .
git commit -m "Initial embedded system monitor"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/embedded-system-monitor.git
git push -u origin main
```

Before running the last two commands:

1. Create a new empty GitHub repository named `embedded-system-monitor`.
2. Replace `YOUR_USERNAME` with your actual GitHub username.

Do not initialize the GitHub repository with another README because this project already includes one.
